2. ¿Es posible que esta captura se haya realizado con el Wireshark instalado en el servidor?

No. Porque el servidor no va a realizar una petición DNS, el cliente es el que inicia la conexión.
Además, las peticiones HTTP se inician desde el origien, cosa que hace el cliente, no el servidor.

4. ¿Qué representan los paquetes 3, 4 y 5?

El inicio de la conexión TCP entre cliente y servidor.
	#3 SYN          cliente  ->  servidor
	#4 SYN, ACK     servidor ->  cliente
	#5 ACK          cliente  ->  servidor
